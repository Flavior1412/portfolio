## Process

Requirements documents follow this lifecycle:

1. **Draft** — Business Analyst agent authors the initial requirements
2. **Review** — Solution Architect reviews for technical feasibility
3. **Accepted** — Design document (ADR) is produced; implementation begins
4. **Implemented** — Developer agent completes all tasks; status updated here
